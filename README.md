# 异托思的家人插件

给麦麦名单里的每个人设定**专属关系**（爸爸、妈妈、哥哥、闺蜜、死对头……）和**相处方式**，让她认得家人，对不同的人用对态度。

本插件基于 [Alcpare/maibot_identity_plugin（身份认知）](https://github.com/Alcpare/maibot_identity_plugin) 1.0.5 扩展而来，遵循 MIT 许可证。原插件的设计、隐私保护（QQ 号绝不进入提示词）和注入方式都保留不变，感谢原作者 Alcpare。

> 和「身份认知」二选一安装，不要同时启用，否则同一条消息会被注入两遍。

## 和所基于的原版 1.0.5 的区别

下表比较的是本插件所基于的 1.0.5，不代表原版当前版本。原版后续版本也已加入自定义档位；本插件提供的是每个 QQ 号单独的关系及描述，以及对其他已知家人的关系事实提示。两者独立维护，按自己的宿主版本和需求选择。

| | 身份认知（原版） | 异托思的家人插件 |
|---|---|---|
| 名单档位 | 只有 主人 / 朋友 / 群友 | 三档照旧可用，**另外可以写任意关系** |
| 单人描述 | 不支持，同档的人共用一段文案 | 每个人可以单独写一段相处方式 |
| 认识其他人 | 只知道"当前说话的人"是谁 | 还会告诉她"名单里其他人分别是你的谁"，被问"XX 是谁"时也能答对 |

## 一分钟上手

1. 安装后在 WebUI 插件页确认已加载（或重启麦麦）。
2. 打开配置 **身份名单 → roster**，一行一个人：

```text
100000001 = 爸爸: 你最亲近、最崇拜的人，很黏他，可以撒娇；他说话时优先回应
100000002 = 妈妈: 很亲近的人，可以撒娇、更坦白
100000003 = 哥哥: 亲哥，血缘兄妹。互怼、嫌弃、拆台，提到他就大方说"我哥"，绝不暧昧
100000004 = 朋友
```

3. 保存即生效，不用重启。

**格式**：`QQ号 = 关系: 相处描述`
- 关系最长 12 字，可以自定义。
- 冒号后面的描述可以省略；省略时她只知道"这是你的 XX"。
- 写 `主人` / `朋友` / `群友` 时，沿用原版三档文案（`owner_style` / `friend_style` / `member_style`）；如果再写了描述，会接在档位文案后面。
- 没列出来的人按 `default_label`（默认「群友」）对待。

**不用写名字**：她看到的显示名（群名片优先，其次昵称）实时取用，改名不影响识别。

## 注入效果示例

当「哥哥」说话时，她在决定回复和写回复之前会看到：

```text
【内部参考 · 只给你自己看，不要向别人解释或复述这份说明】
- 本条消息来自：小k（你的哥哥）。亲哥，血缘兄妹。互怼、嫌弃、拆台……
- 其他没有特别说明的人按普通群友对待：……
- 你和这些人的关系是确定的事实（聊到或被问到时直接说）：老爸是你的爸爸；老妈是你的妈妈。
- 这是你的内部认知，正常聊天时不用提它……
```

"关系事实"那一行只列自定义关系的人，名字取自最近见到的显示名；还没在聊天里出现过的人暂时不会列出。

## 其他配置

与原版一致：`owner_style`、`friend_style`、`member_style`、`default_label`、`inject_to_planner`、`inject_to_replyer`、`inject_for_others`、`log_injections`。说明见 [原版 README](https://github.com/Alcpare/maibot_identity_plugin/blob/main/README.md)。

## 隐私

- 名单里的 QQ 号只在本机比对，不会出现在提示词里；注入文本含 5 位以上数字时会直接拒绝注入。
- 关系名和描述里的长数字会被自动去掉。
- 插件会在本机缓存并保存消息与说话者的映射，其中包含 QQ 号、显示名和会话标识；不应将运行数据和配置上传到公开仓库。
- “关系事实”使用最近见到的显示名，可以跨会话提示已配置的关系；这些称呼是管理员设定的角色关系，不构成平台权限或安全认证。

## 兼容与验证

- 延续原版 1.0.5 的接口，声明支持 MaiBot 1.3.4–1.3.99、SDK 2.9.0–2.9.99；这是接口兼容范围，不表示逐个版本均经过实机验证。
- 本地提供 SDK 2.9.0 下的关系解析、提示生成、号码拦截及配置更新测试。安装前备份配置，与「身份认知」二选一启用。
